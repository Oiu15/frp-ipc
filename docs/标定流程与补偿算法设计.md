# FRP 管检测：参考件姿态误差下的标定流程与补偿算法设计

> 适用范围：外径测径仪（对射双测头，投影/阴影式）+ 内径位移计（背向共线双探头）+ 管件旋转台 + 轴向滑台。
> 设计目标：在显式建模工装误差、偏心、探头不过心的前提下，重新设计标定流程与补偿算法，给出可实现的数学模型与误差预算。
>
> 与现有项目对应：标定参数估计落在 `domain/calibration.py`，几何/汇总纯函数落在 `domain/summaries.py`，参数持久化走 `CalibrationRepository`，正式测量按截面消费标定参数（`frp_workflow/row_math.py` / `domain/summaries.py`）。

---

## 0. 总体思路

放弃"单点公式直接出结果"的做法（即不再把 `OD = B − (a+b)`、`ID = D + L1 + L2` 当作最终值），改为三段式：

1. **正向模型** `M(几何, 工装参数, θ) → 预测原始读数`：把每个传感器的真实位姿（位置、方向、标度、零位）显式参数化。
2. **标定反演**：用几何已知的参考件，最小二乘拟合工装参数（Levenberg–Marquardt）。
3. **生产反演**：固定工装参数，把每次旋转采到的原始读数还原成**机床系边界点**，按编码器角去旋转到**工件系**，对点云拟合圆 / Fourier，分离主轴误差，输出直径、圆度、直线度、同心度。

这样做的根本好处：

- 约束 3（回转中心 ≠ 几何中心，偏心）和约束 4（内径测头不过几何中心）**不需要靠工装消除**，它们在"去旋转 + 拟合圆"里被自然吸收——偏心 = 拟合圆心到回转中心 O 的距离。
- 工装误差（约束 1、2）只进入**一次性标定参数**，不在每次测量里重新犯。
- 单弦/单边的偏置（`h²/r` 量级，可达 0.2mm）由圆拟合彻底消除，残余只对**位姿标定精度**敏感，而不对每次装夹的偏心敏感。

## 1. 坐标系与符号约定

管件**竖放、绕竖直轴旋转**（已确认；与设备高 3565mm、管长 ≥1800mm 一致）。竖放的附带好处：自重弯曲沿轴向作用，横向挠度远小于卧式，对直线度测量有利。

- **机床系**：原点 O 取"回转轴 ∩ 当前截面平面"，x–y 在截面内，z 沿回转轴向上。
- **编码器角** θ：旋转台转过的角度；旋转矩阵 $R(\theta)$。
- **工件系**：固连于管件，θ=0 时与机床系重合。机床系中一个固连于工件的点 $p$，在角度 θ 时位于 $R(\theta)\,p$。
- **截面圆**：外圆真半径 $R_o$、内圆真半径 $r_i$，叠加小形状偏差（Fourier 展开）
  $$\rho(\varphi)=R+\sum_{k\ge2}\big(a_k\cos k\varphi+b_k\sin k\varphi\big),$$
  $k=1$ 项是偏心，不计入形状。
- **偏心**：工件几何中心 $C$ 固连于工件，θ=0 时位于机床系 $e=(e_x,e_y)$；旋转后 $C(\theta)=R(\theta)\,e$，即圆心绕 O 转半径 $|e|$ 的圆。
- **主轴径向误差运动** $\boldsymbol\delta(\theta)$：回转轴自身的非重复/重复跳动，叠加在 $C(\theta)$ 上。
- **传感器位姿**（标定量）：各探头/测径仪的感测原点位置、方向单位矢量、标度 $k$、零位 $o$。

## 2. 正向测量模型（含工装误差）

### 2.1 外径测径仪（投影式线激光，分发光端 + 受光端）

测径仪为**投影式线激光**：发光端投出一片激光幕（fan/curtain），受光端（CCD/光电阵列）接收，管件在光幕中投下阴影，通过**遮光边沿位置**得到轮廓在测量轴 $u$ 上的投影。对一个圆，沿 $u$ 的投影宽度恒等于直径，与圆心在 $u$ 上的位置无关——这是对射两测头对平移不敏感的根源。

> 发光/受光端分置带来一个**专属误差：远心度（位置相关标度）**。若光幕非严格平行（发散）或发受光端未对正，则同一物体在量隙中不同横向位置成像的放大率不同 → 标度随物体位置 $x$ 漂移。量隙 65mm、被测 100–220mm 时管件不居中，该效应可一阶出现。处理：标定时把已知柱规在量隙内**多个横向位置**各测一次，拟合 $k_o(x)=k_{o0}+k_{o1}x$，把位置相关标度也纳入模型（见 §4 Phase 2、§7 参数表）。对射双测头若两端发散一致会部分抵消，但不应默认抵消干净。

设两测径仪沿 $u$ 对射，基线 $B$（两零位间距）。左测头读边沿偏移 $a$、右测头读 $b$。

**对射宽度模式：**
$$
W = B - (a+b) = 2R_o + (\text{偶次谐波项}),\qquad \text{与}\ (e_x,e_y)\ \text{无关}.
$$

> 关键限制：宽度函数 $W(\varphi)=\rho(\varphi)+\rho(\varphi+180^\circ)$ **奇次谐波抵消、偶次谐波加倍**。即对射双测头**测不出奇数瓣（3、5、7 瓣）圆度误差**——这是两点法测圆度的本质盲区。所以宽度模式只能给"等宽意义下的直径"，不能单独给真圆度。

**单边半径模式（推荐用于圆度）：** 只用一个测头，把它当成"相对固定基准的半径探头"。随管件旋转，该测头依次看到外表面每一点的切线位置：
$$
\text{读数}_A(\theta)\ \Rightarrow\ \text{机床系边界点}\ P_A(\theta).
$$
这条轨迹包含**全部谐波**（含奇次瓣），但被偏心（1 次谐波）和主轴误差污染——靠去旋转 + 误差分离处理（§5、§6）。

**工装误差参数（OD）：**

| 参数 | 含义 | 可辨识性 |
| --- | --- | --- |
| $k_o$ | 测量轴标度 | 由两点尺寸标定 |
| $k_{o1}$ | **位置相关标度（远心度）** $k_o(x)=k_{o0}+k_{o1}x$ | 由多横向位置柱规标定 |
| $B_\text{eff}$ | 有效基线/零位 | 由两点尺寸标定 |
| $u=(u_x,u_y,u_z)$ | 测量轴方向（含方位角 $\psi$、出平面倾角 $\beta$） | 倾角对宽度二阶，吸收进 $k_o$ |
| $\Delta z_o$ | 两测头光幕高度差（不共面） | 仅对锥度/弯曲一阶，量级小 |

### 2.2 内径位移计（背向共线双探头）

两位移计**背向**（朝外）安装，感测面间距 $D$，各测到内壁距离 $L_1,L_2$。理想共线时
$$
\text{弦长} = D + L_1 + L_2 = 2\sqrt{r_i^2 - h^2},
$$
其中 $h$ 是探头线到内圆心的垂距。**注意 $h\neq0$（约束 4），所以这是一条弦而非直径。**

一般（带工装误差）模型——把每个壁面命中点写成 3D 机床系点：

- 测头 A 感测面在 $f_A$，方向 $n_A$（含倾斜）：命中点 $\;H_A = f_A + (k_A L_1)\,n_A$
- 测头 B 感测面在 $f_B$，方向 $n_B$：命中点 $\;H_B = f_B + (k_B L_2)\,n_B$

理想背向共线时 $f_B - f_A = D\,n$、$n_A=-n$、$n_B=+n$，退化回上式。工装参数：

| 参数 | 含义 | 是否可忽略 |
| --- | --- | --- |
| $D_\text{eff}, k_A, k_B$ | 基线、两探头标度 | 否，由环规标定 |
| $s$ | 两探头线横向偏移（不共线） | **否，一阶**（见 §3） |
| $\gamma$ | 探头线出平面倾角（不水平） | 标度型，吸收进 $k$ |
| $q(z)$ | 探头线相对 O 的横向位置 | 随 z 变（约束 4），按截面拟合 |

$H_A,H_B$ 都落在内圆上 → 这是把"两个距离读数"变成"两个边界点"的关键，后续用圆拟合而非弦长公式出直径。

## 3. 工装误差可忽略性判断（误差预算）

指标：OD ±0.1mm、ID ±0.01mm、真圆度 **≤35µm（0.035mm）**、直线度 ≤0.01mm、同心度 ≤0.1mm。注：文档另一处的 1µm 是传感器精度/分辨指标，**不是圆度公差**。

**① 测径仪倾斜（不水平）$\beta$：** 宽度过读因子 $1/\cos\beta\approx1+\beta^2/2$。$\beta=0.5^\circ$ 时 $\beta^2/2\approx3.8\times10^{-5}$，在 200mm 上约 **7.6µm**，且为恒定量 → **被标度/零位标定吸收**。结论：对直径**可忽略**（标定后）。

**② 测径仪不共面 $\Delta z_o$：** 直管无影响；锥度 $\sigma$ 时误差 $\approx\sigma\cdot\Delta z_o$。$\sigma=10^{-4}$、$\Delta z_o=2$mm → **0.2µm**。结论：**可忽略**（远低于 35µm 圆度公差）。

**③ 位移计不共线（横向偏移 $s$）：** 这是**重点**。由于探头不过心（约束 4，$h\neq0$），偏移 $s$ 使有效垂距变成 $h\pm s$，对半弦的导数
$$
\frac{\mathrm d}{\mathrm dh}\sqrt{r^2-h^2}=-\frac{h}{\sqrt{r^2-h^2}}\neq0\quad(\text{当}\ h\neq0),
$$
即误差是**一阶**的，量级 $\sim h\,s/r$。$h=3$mm、$s=0.2$mm、$r=76.35$mm（6″ 内半径）→ 约 **7.9µm**，逼近 ID ±10µm。结论：**不可忽略，必须标定 $s$ 与探头线位置**。
（顺带：若直接用 $D+L_1+L_2$ 当直径，单弦本身的 $h^2/r$ 偏置在 $h=3$mm 时已达 **0.24mm**——这正说明必须改用圆拟合，§6。）

**④ 位移计倾斜 $\gamma$：** 弦过读 $1/\cos\gamma$，$0.5^\circ$ 在 152.7mm 直径上约 **5.8µm**，标度型 → **吸收进 $k$**。

**⑤ 偏心（约束 3）：** 对射宽度对偏心免疫；单边/弦长随旋转变化，幅度即 $|e|$。**不可忽略，但靠算法（去旋转 + 圆拟合）分离，而非工装。**

**现实校核：**
- **真圆度 ≤35µm 可达，但需留裕量**。以 ±3µm 测径仪估算，圆度误差下限约 **±15µm**（未计旋转偏心、编码器抖动、装夹误差），落在 ±35µm 公差内；机构误差预算另给 ≤10µm，合成后仍有余量。因此：常规生产用**单边半径模式**即可直接出圆度；接近公差或要稳定裕量时，启用**多步重夹误差分离**把残余压到 ±5µm 量级。（先前"1µm 不可达"的提法基于把精度指标误当公差，按本次更正作废。）
- **同心度受参考件自身同轴度限制**：OD 中心与 ID 中心要在同一机床系里互配准，配准上限 = 参考件两段圆柱的同轴度（§4 Phase 4）。这是整链最薄弱环节。

## 4. 标定流程（仅哑铃参考件，无外部量规版）

> 现场约束（已确认）：可用参考件**只有哑铃件**，两圆柱**同尺寸**（名义 OD 190 / ID 152.7，全长 1700mm）；单柱可达轴向 **<100mm**，内外径在**不同圆柱**、无法同截面同时测、无法复现生产跨度；无环规/量块。
> 工作规格只做 **6″（ID 152.7）**；产品 **OD 有 182.7 与 220 两种**；待测管长 800~1750mm。
> 旋转由**卡盘**带动，工件随卡盘转；**工件相对卡盘的精确再索引不可行**（手动转角误差大）→ 主轴误差分离（反转/多步）均不可行。
> 生产每根测 **6 个截面、轴向跨度 200~240mm**。
> 本节据此重设计，并显式纳入**装夹斜率 τ**。

**核心策略：**

- **绝对尺度**：哑铃 ID 152.7 = 工作内径 → 标定点 = 工作点，ID 标度残差≈0.1µm 可忽略；OD 单点在 190，对 182.7/220 残差 3.7/15µm（见 Phase 1）。只标零位/基线，标度信出厂。
- **圆度**：主轴误差**无法分离** → 单圈直接出、含卡盘误差，靠实测定界（Phase 0）。
- **同心度**：旋转已把内外圆心都锚定到 O → **直接相减**，不强依赖同轴 master（Phase 4 重新厘清）。
- **装夹斜率 τ**：从每根管 6 截面中心线斜率免费测得，跨度 240mm 足够准 → Phase 5。

### Phase 0 — 回转轴直线度 + 卡盘误差定界（不分离）
- **回转轴直线度 `axis(z)`**：哑铃两圆柱相距 ~1700mm，分别测圆心 → **长基线唯一确定回转轴这条直线**（倾斜/位置）。生产 200~240mm 窗口内只需这条直线的线性插值；轴的弯曲（非线性）可用两带数据核查，通常可忽略。注意：回转轴的纯倾斜与装夹斜率一样是线性趋势，会被生产中心线的直线拟合吸收，不必单独扣。
- **卡盘/主轴误差 `E(θ)`：无法分离，只能测幅值定界。** 工件随卡盘转、相对卡盘精确再索引不可行 → 反转与多步分离都做不了。处理：
  1. **区分两部分**：卡盘夹偏 = 1 次谐波偏心 → 去旋转/拟合圆已去除，不计;真正吃预算的是**每圈重复的非 1 次谐波轴误差运动**。
  2. **实测定界**：单圈旋转哑铃圆柱测圆度，与证书圆度比，**超出量 ≈ E 幅值**（不需分离，只看量级）。
  3. **判据**：若 E 幅值 + 传感器噪声 ≪ 35µm → 圆度单圈直接出、把 E 一并报（保守）。
  4. **风险提示**：若为三爪卡盘，径向跳动常 10~50µm，**可能单独超 35µm**。投产前务必先实测此值；超标则需精密卡盘/涨套，或接受圆度指标放宽。
  5. （高级备选，不推荐主用）手动重夹后用工件形状互相关反推实际转角再分离——依赖工件有显著形状、SNR 好，脆弱。

### Phase 1 — 绝对尺度（仅哑铃件，单一尺寸单点标定）
两圆柱同为 OD 190 / ID 152.7 → **只有一个 OD 尺寸、一个 ID 尺寸**。翻转不再给第二个尺寸点，但用于重复性平均、轴向覆盖与互配准。

- **ID（零位/基线）**：哑铃孔旋转 → 去旋转点云圆拟合，以已知 152.7 定 $D_\text{eff}$；$k_A,k_B$ 信出厂值。因标定点 = 工作点（152.7），标度残差≈0.1µm，可忽略。
- **OD（零位）**：哑铃外圆 → 以已知 190 定 $B_\text{eff}$；标度信出厂值。
- **OD 标度残差（实际产品）**：产品 OD 为 182.7 与 220，master 190。单点标定残差 ≈ 标度误差 × 偏离量：182.7 偏 7.3mm → 0.05% 时 **3.7µm**；220 偏 30mm → 0.05% 时 **15µm**（0.02% 时 6µm）。两者均在 ±0.1mm 内（220 端最大约占公差 15%）。**建议**：投产前用一段已知 220 的料核一次实测残差。
- **深度未知**：单柱可达 <100mm，带内多 z 拟合局部锥度、报带内均值，翻转扩展覆盖；圆柱越直，带内均值越接近证书。
- **可选补强**：若要把 220 端再压紧，最低成本是增配一只工作点附近（~220）的外径柱规/量块作第二尺寸点；ID 无此需要。

### Phase 2 — 测径仪轴几何
- 旋转参考圆柱，取**单边支撑序列**；若已做 Phase 0 主轴误差则去除之，残差对照参考件**已知圆度** → 反推测量轴方位 $\psi$、出平面倾角 $\beta$。未做主轴分离时，此残差含主轴误差，作为上界。
- 在 2+ 个可达高度测宽度对照已知 OD，估计 $\Delta z_o$ 与锥度灵敏度（多数情况确认可忽略）。
- **远心度（位置相关标度）**：仅哑铃件时无法把已知件放到量隙多个横向位置 → 退路：① 信任出厂远心度规格并定界；② 若哑铃件可在夹具上整体横移几个已知位置，则借此采点拟合 $k_{o1}$；否则置 $k_{o1}=0$ 并把其上界计入预算。

### Phase 3 — 位移计几何（关键）
- 把探头伸入参考圆柱孔，旋转采 $L_1(\theta),L_2(\theta)$（每圈 100–500 点）。
- 以参考件**已知 $r_i$、已知小圆度**为约束，对工装参数 $\{f_A,f_B,n_A,n_B(\text{含}s,\gamma),q\}$ 与本次装夹的偏心 $e$ 做联合 LM 拟合，目标：去旋转后的命中点云拟合圆半径 = 证书值、圆度残差最小。
- **翻转 + 多角度重夹**作为附加数据：共享同一组工装参数，偏心/圆心作为每次装夹的 nuisance，独立拟合 → 实现 $s$ 与主轴误差、与圆度的分离。

### Phase 4 — 同心度（旋转锚定 O，重新厘清）
**核心认识：旋转把内外圆心都锚定到同一回转中心 O。**
- ID：探头位姿（Phase 3 已锚到 O）→ 命中点去旋转拟合 → ID 圆心 = 相对 O 的偏移。
- OD：支撑函数重建用编码器角（= 绕 O 旋转）→ 重建圆心 = 相对 O 的偏移。
- 两者同在机床 x–y 系（前提：OD 测量轴方位 $\psi$ 已标、编码器零位共用）。

因此 **同心度 = 两个"相对 O 圆心"直接相减**，不需要一个大的坐标系偏移 $\Delta_\text{reg}$。
$$\text{同心度}(z)=\big|\,c_o^{(O)}(z)-c_i^{(O)}(z)-\Delta_\text{reg}^{\text{resid}}\,\big|.$$
$\Delta_\text{reg}^{\text{resid}}$ 退化为一个**小残差**（来自 $\psi$ 标定误差、ID 探头 $q$ 锚定残差），理想为 0；真同轴件应读到 ≈0。

**哑铃件的同轴度限制对同心度因此不再致命**——它原本是用来标大偏移，但旋转已把这件事做掉。哑铃件内外径在不同圆柱、单柱 <100mm、相距 1700mm、不能同截面同测 → **不适合**标 $\Delta_\text{reg}^{\text{resid}}$，但**也不必**。处理：

- **直接出**：令 $\Delta_\text{reg}^{\text{resid}}=0$，同心度直接相减得到，残差量级计入不确定度（用 `ref_coaxiality_uncertainty` 承载）。
- **想验证/收紧**：做一只**便宜的短同轴套管**（一段真管磨到内外同轴、送检同心度），它只需覆盖**一个截面**（不受哑铃跨度/<100mm 限制），同截面同时测内外径、应读 ≈0，反推 $\Delta_\text{reg}^{\text{resid}}$ 填入 `ref_coaxiality_observed`，不确定度收紧。
- 哑铃件对同心度的作用降级为"标传感器位姿($\psi$、探头 $q$)与零位"，这些只需 <100mm 可达深度，足够。

### 处理"深度未知 / 可达深度有限"
- 在可达带内测多个 z，拟合**局部直径斜率（锥度）**，报带内均值；用翻转从两端扩展轴向覆盖。
- 仅哑铃件时绝对尺度**依赖证书**，故深度匹配更重要：圆柱越直，带内均值越接近证书；建议把证书重新规定为"在可达面/指定深度"或给出**全轴向直径廓线**，把残余偏置压到最小，否则计入预算。

### Phase 5 — 装夹姿态固定斜率 τ（无需标定件）
夹爪夹斜 → 管件轴相对回转轴有固定倾角 τ。影响与处理：
- **直线度**：纯刚性夹斜 = 倾斜但仍直的中心线，最佳拟合直线后偏差为 0 → **不影响直线度**（前提管件本身直）。
- **圆度/直径**：水平截面切斜圆柱 = 椭圆，长半轴 $R/\cos\tau$。展开得平均半径偏置 $+R\tau^2/4$、**2 次谐波椭圆假象幅值 $R\tau^2/4$**。幅值随半径增大：OD R=95（190mm）时 τ=2° → 幅值 29µm、**峰峰 58µm（超 35µm 预算）**；τ=1° → 峰峰 ~14.5µm。ID R=76.35 时 τ=2° → 峰峰 ~47µm。**故在本尺寸下此项必须纠正，非可选。**
- **如何得到 τ（免费）**：各截面圆心随 z 拟合直线，其**斜率即 $\boldsymbol\tau=(\tau_x,\tau_y)$**（大小+方位），这串圆心本就为直线度而测。
- **纠正（关键且有坑）**：真实椭圆度与夹斜椭圆度**同为 2 次谐波**，不可直接拟合椭圆去除（会抹掉真实椭圆缺陷）。正确做法：用**独立的一阶量 τ（来自中心线斜率）**预测二阶椭圆假象 $R(\tau^2/4)\cos 2(\psi-\psi_\tau)$ 并只减这一份，残余 2 次谐波才是工件真实椭圆度。
- **变动性**：τ 随每次装夹不同则**逐根按各自中心线斜率纠正**；夹具固定偏差则标一次。**精度充足**：6 截面/240mm 跨度下，τ=2° 产生 8.4mm 横移，圆心测准到几 µm → τ 精度 ~1e-5 rad，椭圆纠正残差 <0.1µm。仅当某些测量窗口被压到很短时才需留意。τ 大且随机时纠正后留残余不确定度，属机械问题，须从夹具对中解决。

**为什么用中心线斜率求 τ，而不是从椭圆反推：**
- **斜率是一阶、椭圆是二阶**：同一 τ，中心线横移 ∝ τ（240mm 上 8.4mm），截面椭圆 ∝ τ²（仅 ~29µm）。用 8.4mm 的信号反推远比用 29µm 的稳，τ 精度高一两个数量级。
- **椭圆会与真实椭圆度撞车**：单截面 2 次谐波 = 夹斜椭圆 + 工件真实椭圆度，一个截面分不开；中心线斜率是**独立的一阶观测量**，不受真实椭圆度干扰。故必须"斜率求 τ → 预测并只减二阶椭圆假象"，否则会把真实椭圆缺陷一并抹掉。
- **τ 不是常数**：含固定项（卡盘轴线偏差）+ 变动项（管端平整度、管子弯曲、卡盘夹持重复性），每次装夹不同 → 必须每根现算，预标的 τ 不能套用。

**τ 的可测性与跨度要求：**
- **至少两个面**：斜率 = 圆心横移 ÷ 高度差，单面无"差"、给不出斜率。证书圆度（7.2~9.3µm）不直接进斜率计算——斜率看的是**圆心位置**（整圈拟合，精度 σ_c≈1~3µm），圆度只限制圆心拟合的准度。
- **跨度公式**：$\ \tau_\text{精度}\approx \sqrt2\,\sigma_c/\Delta L$。哑铃可达 ΔL=100mm、σ_c=2µm → τ 精度 ≈ 2.8e-5 rad ≈ **0.0016°**；代回椭圆假象的传播误差 $\tfrac{R\tau}{2}\tau_\text{err}$（R=95、τ=2°）≈ **0.05µm**。→ **100mm 对哑铃验证 τ 完全够。**
- **测 5~6 面、铺满跨度、对圆心拟合直线**（不是"求平均圆度"）。多面的价值：① √N 抗噪使斜率更稳；② 辨别圆心随 z 是**直线**（纯夹斜）还是**曲线**（哑铃本身弯，不能当 τ 扣）；③ 顺带核查证书圆度/锥度在可测带内是否成立。
- **哑铃 τ 仅用于验证纠正模型**（证书圆 → 实测椭圆 → 斜率算 τ → 预测椭圆是否对得上），**不等于生产管 τ**；生产 τ 仍每根从 6 截面/200~240mm 现算，且生产跨度更大、精度更高。

**哑铃件椭圆的真正用途**：作标定期自检——验证椭圆纠正模型正确，并量出固定卡盘偏差大小；偏差大时应优先从机械上把卡盘对正（源头消除优于软件补偿）。

## 5. 误差分离（本机：不可分离，只能定界）

去旋转后点云里混有主轴/卡盘径向误差运动（固连机床系）与工件形状（固连工件系）。两者要分离，必须改变工件相对主轴的角相位（反转或多步重夹索引）。

**本机条件下两者都不可行**：工件随卡盘转、相对卡盘的精确再索引做不到（手动转角误差大），且哑铃可达范围不支持反转。因此：

- 圆度 = **单圈直接测，含卡盘误差**，不分离。
- 卡盘误差幅值靠 Phase 0 的"哑铃圆柱实测圆度 − 证书圆度"定界；落在 35µm 预算内则可接受。
- `separate_spindle_multistep` 函数仍保留在代码中，供将来若更换为可精确再索引的夹具时启用；当前主路径不调用。
- 通用原理（反转/多步）见下，仅作参考，本机暂不采用：
  - 反转法：探头与工件同步 180° 反向，主轴误差与工件形状反号 → 相加/相减分离。
  - 多步法：工件相对主轴重夹到已知等分角各采一圈，工件系对齐后主轴误差被抹匀。

## 6. 补偿算法（生产，每截面）

输入：一圈内的 $\{(\theta_j,\;a_j,b_j,\;L_{1,j},L_{2,j})\}$；标定参数集（§7）；Phase 0 基准。

```
对每个采样 j：
  # 1. 线性化
  a' = k_o·a + o_a ;  b' = k_o·b + o_b
  L1' = k_A·L1 ;      L2' = k_B·L2

  # 2. 还原机床系边界点（用标定位姿）
  P_od(θ_j)   = 测径仪单边命中点(a' 或 b', 轴 u, 高度修正)      # OD 单边
  H_A(θ_j)    = f_A + L1'·n_A                                  # ID 壁点 A
  H_B(θ_j)    = f_B + L2'·n_B                                  # ID 壁点 B
  # （倾斜 γ：把命中点投影回截面平面）

  # 3. 去旋转到工件系
  P_od_w  = R(-θ_j)·P_od
  H_A_w   = R(-θ_j)·H_A ;  H_B_w = R(-θ_j)·H_B

累积点云：
  OD 点云 = { P_od_w }            # 全谐波，含奇瓣
  ID 点云 = { H_A_w , H_B_w }     # 两条线 → 两簇边界点

# 4. （精测）多步重夹 → 在工件系对齐叠加，分离主轴误差 δ(θ)

# 5. 拟合
  (c_o, R_o, 谐波) = 圆/Fourier拟合(OD点云)     # 几何法 LM，初值用 Kåsa 代数法
  (c_i, r_i, 谐波) = 圆/Fourier拟合(ID点云)
  # 偏心 = |c_o(工件系→机床系映射后绕O的轨迹半径)|，由 1 次谐波给出

# 6. 输出
  外径 = 2·R_o ;  内径 = 2·r_i
  真圆度 = 拟合圆的最大径向跳动（min-zone 或 LSC，扣除已分离 δ）
  对射宽度 W(θ) 作为偶次谐波的独立校核
```

**跨截面（整管）：**

```
对每个截面 z 得 c_o(z), c_i(z)（机床系）
扣除回转轴直线度：c_o*(z) = c_o(z) − axis(z)
直线度 = 拟合 c_o*(z) 为直线后的最大偏移（内/外各算）
同心度(z) = | (c_o(z) − c_i(z)) − Δ_reg − ref_coaxiality_observed |   # Phase4互配准;observed为null时按0,其上界计入不确定度
长度 = 边沿坐标跳变法（测径仪移动中数值突变点）
```

要点：

- ID 不再用 $D+L_1+L_2$ 当直径，只把它当**单条弦**；直径来自点云圆拟合，$h\neq0$ 的偏置被消除。
- OD 直径用对射宽度（稳健、对中性不敏感），OD 圆度用单边半径点云（含奇瓣）。两者互为校核。
- 偏心、探头不过心被"去旋转 + 拟合圆"吸收，无需工装保证对中。

## 8. 实施次序建议

1. 先把 ID 从"弦长公式"改为"点云圆拟合"（约束 4 的一阶误差立刻消除，收益最大）。
2. 加 Phase 1 环规/柱规两点尺度标定（绝对精度稳）。
3. 加 Phase 0 主轴反转标定 + 去旋转圆拟合（偏心、约束 3 解决）。
4. 加 Phase 3 位移计位姿 LM 标定（$s$、$q$）。
5. 同心度直接由"相对 O 的内外圆心相减"得到（Phase 4），$\Delta_\text{reg}^{\text{resid}}$ 先设 0、量级计入不确定度；可选做一只短同轴套管验证并填入 `ref_coaxiality_observed` 收紧。投产前先用哑铃实测卡盘误差，确认圆度预算（35µm）守得住。
